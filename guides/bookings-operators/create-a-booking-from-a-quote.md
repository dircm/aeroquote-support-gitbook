# Create a Flight from a Quote

You can create a flight directly from any accepted quote. This pre-fills the flight builder with the quote's contact, flights, and aircraft details.

### Steps

1. Open an existing [Quote](../quotes/)
2. Click the **Generate a Flight** button on the quote's detail page
3. The [flight builder](booking-builder.md) opens with the quote details pre-filled
4. Review and adjust the details — dates, aircraft, and passenger information may need updating
5. Follow the builder steps through to **Create Flight**

Your new flight opens automatically on the flight detail page.

If the quote legs had **planned fuel burn** from an advanced performance estimate, that figure is copied onto the flight legs. You will see it next to duration on **Itinerary** and on crew/manifest views (not on the customer page). See [Advanced performance models](../aircraft/advanced-performance.md).

{% hint style="info" %}
You can also create flights from scratch (without a quote) using the **Create Flight** button on the Flights page. See [Creating a Flight](booking-builder.md) for the full step-by-step guide.
{% endhint %}
