# ⏱️ Flight Time Limits

When **FTL / Crew Limits** is enabled, AeroQuote tracks crew duty and flight hours against configurable profiles, as a planning and record-keeping aid. Your operations manual governs.

## Guides

* [FTL Dashboard & Summary](ftl-dashboard-and-compliance.md) — duty overview, timeline, daily flight-time cap, and the Flight and Duty Time Summary

Enable the module under **Settings → Modules** before these features appear in the sidebar.
