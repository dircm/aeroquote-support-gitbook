# Contacts

{% hint style="info" %}
If you use a contact as a passenger, you should edit the contact weight so payload calculations are accurate.
{% endhint %}

<details>

<summary>Listing all Contacts</summary>

Click the <img src="../../.gitbook/assets/contacts menu item.png" alt="" data-size="line"> Contacts menu item to open the list of contacts.

![](<../../.gitbook/assets/contacts page.png>)

From this page, you can:

* **Add new Contact** - Click this button to add a new contact. [See how](add-a-new-contact.md)
* **Import CSV** - use this feature to upload a CSV of contacts. [See how](import-contacts.md)
* **Export metrics** - download the contacts shown, with quote and flight metrics, as an Excel workbook (admins only). [See how](export-contacts.md)
* **Import baselines** - load opening flights, hours and distance from a CSV. [See how](contact-baselines.md)
* **Frequent flyer settings** - change the tier thresholds (Settings - Edit only). [See how](contact-metrics.md#frequent-flyer-tiers)
* **Search** - search for contacts by name, email, company name, phone, or notes.
* **Filter** - by passenger or contact, flight type, dates flown, minimum flights or hours, recency and frequent-flyer tier. [See how](contact-metrics.md#filters)
* Edit a Contact - click the <img src="../../.gitbook/assets/contact edit button.png" alt="" data-size="line">button to open the edit contact window.
* **Baseline** - set a contact's opening figures. [See how](contact-baselines.md)

Each contact also shows their quote history, flights, hours, distance, last flown date and a suggested frequent-flyer tier. [See what the figures mean](contact-metrics.md)

{% hint style="info" %}
You need the **Contacts - View** or **Contacts - View All** permission to open Contacts.
{% endhint %}

</details>
