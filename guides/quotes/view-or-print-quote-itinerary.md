# View or print the full quote itinerary

Use this guide when you need a **printable full itinerary** from a quote (for yourself, ops, or the customer). AeroQuote has more than one PDF path — pick the one that matches what you need.

***

## Which option should I use?

| Goal | Where | Control |
| --- | --- | --- |
| **Customer-ready itinerary / quote package** (branded PDF, placeholders, attachments) | Quote → **Documents** step | Preview in page, **Preview Document**, or **Download PDF** |
| **On-screen customer itinerary** (no download) | Quote → **Options** / **Flight** step | **Customer View** |
| **Internal job details PDF** (contacts, legs, totals for selected options) | Quote → **Quote Details** step | **Job details** → **Download PDF** (only after accept / paid / booking-generated) |
| **Post-booking customer itinerary** | Booking (not the quote) | Booking customer page / itinerary download |

***

## Option 1: Customer-facing itinerary PDF (recommended for “print complete itinerary”)

This is the PDF built from your document library placeholders and templates — the same package you can attach when sending the quote.

### Steps

1. Open the quote from **Quotes** or the **Dashboard**
2. Click the **Documents** tab at the top of the quote
3. Under **Selected Documents (email attachments)**, add a **placeholder** document from the library (sidebar) if none is selected yet — this generates the live quote itinerary content
4. Optionally add other PDF/library documents to include as attachments
5. On desktop, scroll to **Quote Placeholder Preview** to review the full document
6. Click **Download PDF** to save a printable file  
   *On small screens, use **Preview Document** to open the PDF in a new tab, then print from the browser*

{% hint style="info" %}
If the preview area is empty, add a placeholder document from the library and pick a style if prompted (**Pick a style**). See [Using Documents in a Quote](../documents/using-documents-in-a-quote.md).
{% endhint %}

### Tips

* Use **Load Template** to apply a saved document set
* Use **Save as New Template** after arranging documents you reuse often
* Sending to the customer: open the **Send** step and include attachments so the customer gets the same package by email

***

## Option 2: Preview the itinerary on screen (Customer View)

Useful when you only need to **see** the full customer itinerary without downloading a PDF.

1. Open the quote
2. Click **Options** (or **Flight** if there is only one option)
3. Click **Customer View** (toggle next to **Admin View**)
4. Review the customer-facing itinerary layout
5. Switch back to **Admin View** to edit flights, costs, or options

This is a live preview, not a separate print-optimised PDF. For printing, use **Option 1**.

***

## Option 3: Internal job-details PDF from Quote Details

Available when the quote is **Accepted**, has **Partial payment**, is **Paid**, or has a **Booking generated**.

1. Open the quote on the **Quote Details** tab
2. Expand **Job details** if collapsed (**View**)
3. Click **Download PDF**

This PDF includes main contacts, selected option aircraft, and flight rows (departing, duration, arriving, pax), plus totals. It is aimed at **internal / ops** use, not the full branded customer document.

***

## Quote vs booking itinerary

| Stage | What to use |
| --- | --- |
| Still quoting | **Documents** PDF or **Customer View** on the quote |
| Already booked | Open the **booking** — customer itinerary / confirmation is managed on the booking (and customer page), not only on the original quote |

Generating a booking from a quote: [Create a Booking from a Quote](../bookings-operators/create-a-booking-from-a-quote.md).
